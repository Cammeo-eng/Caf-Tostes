# TOSTES&CO — cardápio digital

Cardápio digital mobile-first da TOSTES&CO, cafeteria artesanal em Fazenda Rio Grande (PR).

- `PROMPT.md` — briefing do projeto
- `cardapio-dados.md` — fonte de verdade do cardápio
- `DECISOES.md` — registro das decisões
- `web/` — site (Next.js, TypeScript, Tailwind CSS)

Para rodar localmente:

```bash
cd web
npm install
npm run dev
```
